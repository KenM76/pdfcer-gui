## 4. ★★★ The methodological findings. These are the valuable part.

### A citation supporting your theory may be about a different document

His typo was **diagnosed wrong twice in one day**, and the second was worse than
the first because it had evidence.

1. *"`Identity-H` fonts cannot be written to."* Retracted after editing one of
   the very faces called unwritable.
2. *"Extraction synthesises the spaces on his line, so no matcher can reach the
   string."* This had a **real citation** — a comment recording a title-block
   cell whose extraction produced twenty-one synthesised spaces. False on **his**
   file: 36 characters, 36 operators, spaces included.

The actual cause was one clause of the engine's new capability — **a pinned
request never spans show operators** — so the pin the shell added *for safety*
was switching off the matcher it needed.

★★ **And the fix I proposed would have made it worse.** I suggested sending only
the changed span. On that page the changed span (`"n"` → `"nt"`) occurs **33
times**; the whole run occurs **once**. Narrowing the find *widens* the
ambiguity — on a signed quotation.

⇒ **A brief that names a cause invites the agent to confirm it.** Both times the
outcome was saved by an agent measuring instead of building what it was asked
for. Write briefs that name the symptom and the instruments, mark any hypothesis
as one to falsify first, and say plainly that overturning it is the most
valuable thing they can report.

### A gate keyed on a name is discharged by prose

`verb-coverage.py` scored an engine verb "consumed" if its name appeared
anywhere under `crates/pdfcer-gui/src`. `pdfcer_core::sign` — 101 items, a whole
signing subsystem built in answer to *this project's own request* — was scored
consumed because the word `sign` appears in a doc table about **the arithmetic
sign of `/Count`**.

Tightening it to call-shape with comments blanked moved **25 verbs** from "named"
to "named nowhere", and every mention of them turned out to be a comment.
**Every verb whose name is also an ordinary English word — `sign`, `merge`,
`split`, `count`, `set`, `move`, `insert`, `close`, `open` — was permanently and
silently exempt.**

★ And the register check had the mirror defect: a paragraph naming five verbs in
backticks **to say they were out of scope** took the gate from naming five to
`PASS: all 41`. *Prose about a verb is indistinguishable from prose accounting
for one.* Now restricted to table rows.

### Writing a thing down is not doing it — five instances in one week

`cut_pages`' comment ends *"Recorded here so the next reader does not
rediscover the constraint by trying."* `transform_preview`'s begins *"THE
PREFLIGHT IS NOT BUILT, AND THIS IS THE NOTE THAT SAYS SO."* `app/blank.rs`
recorded that the engine had shipped the page-resize verbs on 2026-08-18.

★★★ **The exception proves it:** `set_media_boxes` was the one verb of
twenty-one with **no sentence anywhere** about why it was not called — and it
was the largest gap. *The verb nobody wrote a sentence about is the capability
nobody noticed.*

### Never Debug-format a value a machine reads — three instances

`character={missing:?}` on an `Option<(char, String)>` made a driven check report
**THE OFFER DOES NOT NAME THE CHARACTER** while quoting the offer naming it.
`said={why:?}` turned two checks red against a working build when a variant
gained a payload. `field={:?}` on an `Option<String>` emitted
`field=Some("SignHere")` into a `key=value` trace a verdict rested on.

**Fix the emitters, never loosen the comparison** — loosening leaves two
surfaces describing one fact in two languages and hides the next mismatch.

### A driven failure is a claim about the check too

Of the apparent application defects found by driving this session, **most were
the check**. Two checks written by sessions that were forbidden to drive failed
on their first real run for their own reasons — one compared two differently
shaped trace fields, one never said which mode it needed and looked for a Pages
tab in **Read**, where that tab correctly does not exist.

⚠ **Triage before fixing.** And note the second one twice: the SKIP was honest,
precise, and useless — it named the missing region exactly and even offered the
right diagnosis as an alternative reading.

### A gate whose input set changes at `git add` time cannot vouch for a commit

`check-old-name-absent` uses `git grep`, which scans **tracked** files. The same
tree gave two verdicts twenty minutes apart — clean while a captured trace was
untracked, red the moment a commit added it — and the red one arrived inside the
packager's pre-flight, *after the release had been declared ready*.

### A gate whose verdict depends on whether the tree is dirty

`build.rs` emitted an **empty string** for `PDFCER_RELEASE_MODIFIED` on a clean
tree, and the consumer compares it with `== "1"`. `env!` expands to a literal, so
clippy saw `"" == "1"` and fired — and `cargo clippy` is a gate. It passed all
day on a tree carrying uncommitted work and went red the instant the tree was
clean, **which is exactly when a release is cut**.

### A hand-maintained list that has been the bug four times

`canvas/interact.rs` built the page's object model only when a hand-written list
of gesture outcomes said so. `Resize`, `Handle` and `DimensionVertex` each
shipped needing it and not asking. The fourth instance was **unfixable by adding
a fourth entry** — Delete is a keystroke, not a gesture outcome. Now
`canvas/modelneed.rs`, whose gesture half is an **exhaustive match with no
wildcard**, so a new variant is a compile error.

### `RESUME.md`'s head aged into a falsehood, twice

A `⬜ DO THIS FIRST` block is written when it is the most urgent thing, so it
goes where it cannot be missed — and is then discharged **in the code**, where
that file cannot see it. A session read it, went to do the work, and found it
already done. **Strike the block in the same commit as the code.** That rule was
written this session and was obeyed the very next time.
