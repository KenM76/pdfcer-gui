ROW: O75 (second half) — Properties always shows "This document" | root-cause-found | conf high
SUMMARY: The prior diagnosis is confirmed exactly. `body_sections` draws six selection-scoped sections (markup, ce dimension, annot-delete, form field, text, geometry) plus `object_section`, each of which early-returns when it has no subject — and then calls `info::section` at `mod.rs:363` with no condition of any kind. `info::section` (`info.rs:186`) has no gate inside it either: it publishes its region, prints the "This document" heading and note, then always draws the five read-only facts and the four `/Info` editors. So the heading is on screen every frame a document is open, and when nothing is selected it is the only thing there. The six `drew_*` booleans exist and are already OR'd — but as an inline expression at `mod.rs:355-360` passed straight into `object_section`, never bound to a name, so nothing else can read it. Binding it to a `let` and threading it into `info::section` is a two-line change; that disjunction is the right predicate and needs no new derivation, but it is incomplete on its own because `object_section` itself draws and does not report that it did. On coverage, the prior sweep is right that geometry refuses two objects (`geometry.rs:342`) and that bookmarks and pages have no Properties surface at all, but wrong about multi-selection having "no surface": `object_section` silently describes the FIRST object of the set (`mod.rs:406-410`) under an "Object properties" heading with nothing saying it is one of several — worse than nothing, because it is a true readout attached to a false subject. On egui 0.35: `CollapsingHeader::default_open` is consulted only through `load_with_default_open` at `collapsing_header.rs:541`, which returns stored state whenever one exists (`:50-58`), so it is dead after frame one; and `open(Some(_))` at `:542-550` forces state every frame but moves click handling into an `else` branch, removing the operator's ability to expand by hand. Neither works alone — the correct shape is an edge-triggered `CollapsingState::set_open` + `store`.

THE PREDICATE'S HONESTY, which matters more than the mechanics: the rule is 'collapse when something else is speaking about the selection', not 'collapse when something is selected'. `annotdelete::section` returns false on an ordinary unlocked annotation in an unsigned document (annotdelete.rs:488-490) and `text::route` returns false for a non-text object (text.rs:689-691) — so for a selected image or path the only speaker is `object_section`, which is why (1)'s `drew_object` return is load-bearing rather than tidy. Without it, a single selected path — the commonest selection in this operator's CAD files — collapses nothing.

WHAT NOT TO DO: do not gate the call (`if !anything { info::section(..) }`). That is hiding, and R9 forbids it — the metadata form IS available on every open document, including one with no `/Info` at all (`set_info_field` creates it; info.rs:181-185). Collapsed is disclosure: the heading and the twisty stay on screen and one click restores the form.
