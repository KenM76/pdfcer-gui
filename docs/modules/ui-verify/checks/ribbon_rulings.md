# `ui-verify/checks/ribbon_rulings`

`the_ribbon_says_what_its_controls_do` — the four wording rulings of O403, driven off
the desktop with the scripted pointer on a page built at run time. F11's is
`read_mode_hides_the_chrome`'s, which needs the real desktop.

| Phase | Move | Oracle |
|---|---|---|
| Page display | open View | each of the four buttons is wider than an icon alone, and the group is photographed |
| Find button | Ctrl+F, type, press the button, press again, Enter | `find-bar` goes from no match shown to match 1 only on the button, then 2, then 3 by Enter, so the caret went back to the field |
| Selection | select text in Read, then in Edit | `ribbon.tab.format` is wider in Read than in Edit: Selection is longer than Format, and the region is one region |
| Collapsed words | a narrow window | `ribbon.group.file.document.collapsed` is wider than its caption and chevron alone |

Widths stand in for the words because the harness reads no text off a painted
button; the photographs under the check's output folder show the words themselves.
