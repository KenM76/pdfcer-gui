# `editmodel::reface` — the characters a commit sets in another face

`Reface` is what a commit carries when some of its characters must be set in
another face: the face's selector (handed to the engine as
`FallbackFace::Named`), its label as the operator reads it, and the
characters. Planned at the keystroke by `pdfcer-gui::canvas::textedit::reface`
and committed by `pdfcer-gui::app::actions::reface`.
