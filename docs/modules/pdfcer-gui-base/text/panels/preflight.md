# `text::panels::preflight` — the Preflight panel's words

Every string the Preflight panel shows: plain names for the built-in
profiles, the run, progress, cancel and stale lines, the clean and summary
headlines, the three finding kinds (Violation, Needs a person, Incomplete —
never worded as a pass), row text, Copy report, and the fixes with their
greyed reasons. Kept apart from the panel so the wording is reviewed in one
place.
