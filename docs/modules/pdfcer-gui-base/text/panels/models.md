# `text::panels::models` — every string the 3D models section and its verbs show

Covers `pdfcer_gui::panels::attachments::models` and
`pdfcer_gui::app::actions::models`: the heading, count and row text, the
listing caveats, the Save button and its tip, the insert picker's title and
filter, and every outcome note — placed, saved, refused (STEP named with the
advice to convert to PRC or U3D), unreadable, gone, format mismatch,
unrecognised data, and the PDF-version warning. Rich-media asset names are
the document's own and have control characters removed before display.
