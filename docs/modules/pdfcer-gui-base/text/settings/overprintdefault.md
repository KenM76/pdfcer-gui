# `pdfcer-gui-base/text/settings/overprintdefault`

The words of Settings ▸ Display ▸ **Use overprint preview**: the title, the
silence and radius lines every setting carries, and one label and one note per
[`OverprintDefault`](../../prefs/overprint.md) choice.

The labels are Acrobat's own ("Only for PDF/X files", "Always", "Never",
"Automatic") so an operator who knows that setting finds it here unchanged.
`Always` carries "(pdfcer's default)" because it is the one choice where
pdfcer's default differs from Acrobat's.

Distinct from [`overprint`](overprint.md), which words the engine's zero-tint
rule — *how* overprint is drawn, not *whether* the preview starts on.
