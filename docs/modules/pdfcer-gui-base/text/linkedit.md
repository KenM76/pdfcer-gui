# `text::linkedit` — the words for adding and editing a link

Every operator-visible string of the Add-link window, the Properties link
section, and the link verbs' status lines and refusals.

- Refusals the form decides (`needs_web`, `web_not_ascii`, `needs_name`) are
  shown beside the absent commit button.
- Engine refusals are worded by `app::actions::links`: `name_not_found`,
  `uri_invalid(reason)` (the engine's reason appended), `width_invalid`,
  `no_area`.
- Disclosures: `replaced_action(kind)` when re-pointing removed an action, and
  `appearance_replaced` when a border change replaced another program's drawn
  appearance.
