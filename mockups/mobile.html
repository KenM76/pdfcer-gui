pdfcer on Android: proposed interface

A proposal, not yet approved. The commands, the Read / Review / Edit modes and the off-canvas disclosure rule are the desktop program's, unchanged. What changes is where commands are placed and how gestures map onto them. A phone gets its own layout; a tablet gets the desktop ribbon resized for fingers. The design argument is in MOBILE_DESIGN.md.

1 · Phone, Read: what someone opening an emailed drawing sees

The page fills the screen. One finger pans, two fingers zoom, a double-tap fits the width. The bottom bar holds the four things a reader reaches for. The mode switch sits in the top bar and is the only door to authoring. One tap on the page hides the bars; another brings them back.

2 · Phone, Review: marking up with a finger or a stylus

Choosing Review changes the bottom bar to markup tools. The desktop's ribbon tabs become the tool sheet: drag up from the bottom bar. Its tab chips are the manifest's tabs in the same order, with the same groups and commands, laid out in a four-column grid. A stylus draws and a finger pans, so someone can mark up while scrolling, which is how Samsung Notes and Xodo behave.

3 · Phone, selecting and changing something already on the page

Tap selects. A long press opens the context menu, the same menu a desktop right-click opens. A selected item gets handles big enough for a finger, and its properties open as a sheet that holds the desktop's Format tab and Properties panel.

Panels become full screens on a phone. Each of the sixteen desktop panels opens as a page with a back arrow. Tapping a comment goes back to the page and selects it. On a tablet the same panel docks at the side instead.

4 · Tablet, landscape: the desktop layout, sized for fingers

At 840 dp and wider the program uses the desktop layout: ribbon, rail and docks. Items are taller, groups fold sooner, the Quick Access Toolbar moves into the tab row, and the right dock is one tabbed column rather than a split. The pen-draws, finger-pans rule and the magnifier still apply.
