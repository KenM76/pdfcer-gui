The rule that makes this safe

A mode changes what is visible. It never makes a visible control silently inert. That is the entire difference between this and the editing_enabled master toggle removed two turns ago — that one left the tools on screen and made gestures quietly fail.

Removed editing_enabled toggleRead / Review / Edit
VisibilityHidden binary in one ribbon groupNamed control, always on screen, current position visible
When offTools still shown, clicks do nothingTools are not there to click
FeedbackNone at the point of failureA badge stating the stance, and why if the document forced it
GranularityAll-or-nothingThree ordered levels, each a superset of the last
Undo—Untouched. Undo reaches across a mode change.
  • Each mode remembers its own layoutLeaving Edit and coming back restores your arrangement, not a default. Modes are named workspaces.
  • A document can force a modeSigned, encrypted, or read-only-on-disk opens in Read with the badge saying why — earlier than today, where you can arm a tool that later refuses.
  • Not a permissions systemRead mode protects nothing; the operator can move the slider. It is an interface-complexity control, and the badge says which stance you are in.
